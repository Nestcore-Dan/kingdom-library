# Principles

* You can build a custom AI agent platform by prompting a coding agent to assemble existing open-source components.[^SRC-KB-0013] _(unreviewed, unknown confidence)_
* Hermes Agent serves as a model-agnostic harness that can integrate any LLM and connect to existing APIs and tools.[^SRC-KB-0013] _(unreviewed, unknown confidence)_ [10:30](https://www.youtube.com/watch?v=ceU0tS6sXbU&t=630s)
