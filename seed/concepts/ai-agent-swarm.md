A method of deploying multiple AI agents to collaboratively reverse-engineer and rebuild software platforms.

# Principles

* AI agents can autonomously reverse-engineer complex platforms by dividing tasks among multiple agents and using shared specifications.[^SRC-KB-0014] _(unreviewed, unknown confidence)_
* A unified specification can be generated from multiple agent findings and used to reconstruct a functional platform.[^SRC-KB-0014] _(unreviewed, unknown confidence)_ [1:30](https://www.youtube.com/watch?v=OEqm3w_7ACg&t=90s)
* UI cloning and browser automation can be used to reconstruct the visual interface of a platform without direct access to its code.[^SRC-KB-0014] _(unreviewed, unknown confidence)_ [13:30](https://www.youtube.com/watch?v=OEqm3w_7ACg&t=810s)
