# Principles

* Cloud desktops and virtual machines enable agents to perform tasks requiring physical compute.[^SRC-KB-0001] _(unreviewed, unknown confidence)_
* Abstract client-facing tools (e.g., Orgo) to maintain control and avoid exposing internal infrastructure.[^SRC-KB-0007] _(unreviewed, unknown confidence)_ [6:00](https://www.youtube.com/watch?v=pjvT25T_81o&t=360s)
* Consistent deployment and standardized interfaces (like Hermes Agent) enable fair and repeatable benchmarking across different models.[^SRC-KB-0006] _(unreviewed, unknown confidence)_ [4:30](https://www.youtube.com/watch?v=BFRmOxT8QIo&t=270s)
* Model-specific strengths (e.g., Grok 4.5’s creativity) can be valuable but may not translate to practical task performance without optimized prompting or orchestration.[^SRC-KB-0006] _(unreviewed, unknown confidence)_ [22:30](https://www.youtube.com/watch?v=BFRmOxT8QIo&t=1350s)
* Claude Opus 4.5 is the current best model for computer-use tasks, hosted via Orgo.ai.[^SRC-KB-0003] _(unreviewed, unknown confidence)_ [1:30](https://www.youtube.com/watch?v=t6wWLVd-C_I&t=90s)
* The workflow can be built without writing code, using tools like Orgo, n8n, or Zapier to orchestrate actions.[^SRC-KB-0003] _(unreviewed, unknown confidence)_ [4:30](https://www.youtube.com/watch?v=t6wWLVd-C_I&t=270s)
