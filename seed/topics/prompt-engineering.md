# Principles

* You can build a custom AI agent platform by prompting a coding agent to assemble existing open-source components.[^SRC-KB-0013] _(unreviewed, unknown confidence)_
* The entire platform can be built from scratch using one prompt and a coding agent, with no prior coding required.[^SRC-KB-0013] _(unreviewed, unknown confidence)_ [15:00](https://www.youtube.com/watch?v=ceU0tS6sXbU&t=900s)
* Real-world performance of AI agents depends not just on model capability, but on the orchestration platform, runtime, and task-specific prompting.[^SRC-KB-0006] _(unreviewed, unknown confidence)_
* Model-specific strengths (e.g., Grok 4.5’s creativity) can be valuable but may not translate to practical task performance without optimized prompting or orchestration.[^SRC-KB-0006] _(unreviewed, unknown confidence)_ [22:30](https://www.youtube.com/watch?v=BFRmOxT8QIo&t=1350s)
