This beginner tutorial walks viewers through setting up Obsidian, creating and formatting notes with Markdown, linking notes together, using the Graph View, searching across notes, connecting AI tools like Claude via Zapier, installing plugins, and syncing notes across devices using Obsidian Sync.

# Core method

Start by downloading and installing Obsidian, create your first vault, then create and format notes using Markdown syntax. Link notes with double brackets, visualize connections in Graph View, search across your vault, connect AI tools via Zapier, install plugins for extended functionality, and use Obsidian Sync to keep notes synchronized across devices.

# Key takeaways

* Create a local vault in Obsidian by selecting a folder and clicking 'Create'.
* Format notes using Markdown: headings with ##, checklists with - \[ \], bulleted lists with -, and numbered lists with 1. .
* Link notes using double brackets \[\[ \]\] to create internal references and visualize connections in Graph View.
* Search across your entire vault using the sidebar search to find specific content quickly.
* Connect AI tools like Claude to Obsidian via Zapier MCP to automate note updates and retrieve information.
* Install community plugins to extend Obsidian’s functionality, such as Templater or Dataview.
* Use Obsidian Sync (paid) to sync notes across devices, though it’s not free.
