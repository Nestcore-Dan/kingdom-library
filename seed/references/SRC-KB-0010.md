Nick Vasilescu demonstrates how he built Bops, a business operations platform for AI agents, over a weekend using tools like Paper for design, T3 Code for development, and integrations with Orgo, AgentMail, AgentPhone, Composio, and OpenAI. The system allows agents to perform tasks via phone, text, or app, with persistent memory and cross-platform access. He shows how to configure agents with tools, connect them to real-world services, and deploy them for business automation.

# Core method

Design your AI agent platform in Paper first, then build the backend using T3 Code with Claude Opus 5.5 for guidance. Integrate agent-specific tools like Orgo computers, AgentMail, AgentPhone, Composio, and Treg to enable real-world functionality. Use OpenAI’s Harness API and GPT-6.1 for agent logic and voice interaction. Deploy and test with real user interactions across platforms.

# Key takeaways

* Agents can be designed and built in a weekend using Paper and T3 Code with Claude Opus 5.5.
* Orgo computers enable agents to run tasks on real machines with persistent memory.
* AgentMail and AgentPhone provide email and phone interfaces for agents, managed via Composio.
* Treg acts as an open-source tool router for accessing thousands of APIs with one credential.
* OpenAI’s Harness API and GPT-6.1 model can be used to power agent logic and voice interaction.
* Agents can be configured to handle calls, texts, emails, and screen monitoring via tools like JEV.
