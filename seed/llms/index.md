# LLMs

* [Claude](cursor.md) - An AI-powered code editor and agent platform that integrates with Claude to build and configure computer-use agents for automation tasks.
* [DeepSeek V4 Flash](deepseek-v4-flash.md) - An AI language model from DeepSeek, exhibiting erratic or unstable behavior in real-time computer use.
* [deepseek/deepseek-v4-pro](deepseek-deepseek-v4-pro.md) - A large language model used by the Hermes Agent for task execution and model switching.
* [Fable 5](fable-5.md) - An AI language model from Anthropic, designed for creative and complex tasks, but underwhelming in practical agent use.
* [Fable 5.2](fable-5-2.md) - An AI model used in the orchestration process for agent coordination and task assignment.
* [GLM 5.2](glm-5-2.md) - An AI language model from Zhipu AI, used in agent benchmarks but underperforming in practical tasks.
* [Google Gemini 3.5 Flash](google-gemini-3-5-flash.md) - A large language model from Google used as a default model for agent orchestration.
* [google/gemma-4-31B-it](google-gemma-4-31b-it.md) - A Google language model used to correct OCR errors and assign domain/topic/register labels.
* [GPT-5.5](gpt-5-5.md) - A large language model used as the cognitive engine for AI agents like Hermes Agent.
* [GPT-5.6 Sol](gpt-5-6-sol.md) - An AI language model from OpenAI, optimized for real-world agent tasks with high speed and reliability.
* [GPT-6.1](gpt-6-1.md) - A large language model from OpenAI used to power agent logic and voice interaction.
* [Opus 5.5](claude-opus-5-5.md) - A high-performance language model from Anthropic used to guide agent design and backend development.
* [Opus 6.5](opus-6-5.md) - A specific version of the Claude model family, used for AI agent and content generation tasks.
* [Terra](terra.md) - An AI language model from OpenAI, part of the GPT-5.6 family, excelling in practical agent tasks.
* [Veo 3.1](veo-3-1.md) - An AI video generation model used in Higgsfield and replicated in Parallax for video creation.
