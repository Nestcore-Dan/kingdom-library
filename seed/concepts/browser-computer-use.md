The field of AI agents that interact with and control computer systems, including web browsers and desktop applications.

# Principles

* The agent can generate a live web interface, manage multiple bots, and control remote computers via screen-sharing.[^SRC-KB-0013] _(unreviewed, unknown confidence)_ [9:00](https://www.youtube.com/watch?v=ceU0tS6sXbU&t=540s)
* Pre-configure browser tabs to avoid repeated logins or navigation.[^SRC-KB-0002] _(unreviewed, unknown confidence)_
* Use AI agents to switch contexts and input data without manual intervention.[^SRC-KB-0002] _(unreviewed, unknown confidence)_ [4:30](https://www.youtube.com/watch?v=gHCZzYBZy4U&t=270s)
* Set up agents to remain running for repeated use, with optional termination to save costs.[^SRC-KB-0002] _(unreviewed, unknown confidence)_ [12:00](https://www.youtube.com/watch?v=gHCZzYBZy4U&t=720s)
* Use AI agents to extract structured data from web pages and populate it into Google Sheets.[^SRC-KB-0002] _(unreviewed, unknown confidence)_ [13:30](https://www.youtube.com/watch?v=gHCZzYBZy4U&t=810s)
* Use AI agents to automate workflows without requiring API integrations or backend code.[^SRC-KB-0002] _(unreviewed, unknown confidence)_
