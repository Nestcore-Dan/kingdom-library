# Tool-specific tips

* To create a new note in Obsidian, click on the 'New note' button in the left sidebar and enter a title.[^SRC-KB-0015] _(unreviewed, unknown confidence)_ [1:30](https://www.youtube.com/watch?v=lsytBlAdJK4&t=90s)
* To format text in Obsidian, use Markdown syntax such as ## for headings, - \[ \] for checklists, and - for bulleted lists.[^SRC-KB-0015] _(unreviewed, unknown confidence)_ [3:00](https://www.youtube.com/watch?v=lsytBlAdJK4&t=180s)
* To link notes in Obsidian, use double brackets \[\[ \]\] to create internal references.[^SRC-KB-0015] _(unreviewed, unknown confidence)_ [7:30](https://www.youtube.com/watch?v=lsytBlAdJK4&t=450s)
* To search for content in Obsidian, use the search bar in the left sidebar to find specific content across your vault.[^SRC-KB-0015] _(unreviewed, unknown confidence)_ [9:00](https://www.youtube.com/watch?v=lsytBlAdJK4&t=540s)
* To install plugins in Obsidian, go to the 'Settings' menu and select 'Community plugins' to browse and install plugins.[^SRC-KB-0015] _(unreviewed, unknown confidence)_ [12:00](https://www.youtube.com/watch?v=lsytBlAdJK4&t=720s)
