# Human-1M knowledge

Knowledge that belongs to [Human-1M](../human-1m.md).

* [Quality Gates](quality-gates.md) - A set of automated and human-reviewed checks ensuring high-quality annotations, tasks, diversity, and 3D tracking.
* [T1](t1.md) - A high-level task description in Human-1M, summarizing the overall goal, major actions, and key objects.
* [T2](t2.md) - A timed subtask annotation in Human-1M, specifying 1–10-second segments with precise verbs and objects.
* [Task Clusters](task-clusters.md) - Groupings of similar tasks within the Human-1M dataset, used to organize and analyze human work.
