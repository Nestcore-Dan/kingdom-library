Nick Vasilescu interviews Karsten Stinis, who installs and manages AI agents for Belgian businesses at €2,750 setup + €250/month support. The process involves onboarding clients with a pre-built agent that integrates tools like Orgo, Hermes, Composio, and Honcho, enabling immediate value. Karsten uses an agent named 'Jeff' to automate setup, monitor performance, and handle support tasks, creating a scalable, low-overhead model.

# Core method

Build a pre-configured AI agent stack using tools like Orgo, Hermes, Composio, and Honcho. Onboard clients by delivering a functional agent on day one, using tools like Fireflies.ai to capture workflows. Monitor agent performance via a dashboard (Agentiek) and use an agent (Jeff) to auto-resolve issues and escalate when needed. Charge a setup fee + monthly retainer for ongoing support and maintenance.

# Key takeaways

* Charge €2,750 for setup + €250/month for support, delivering a working agent immediately.
* Use an agent (Jeff) to automate agent deployment, monitoring, and issue resolution.
* Integrate tools like Orgo, Hermes, Composio, Honcho, and Telegram for a cohesive stack.
* Use Fireflies.ai to record client workflows and tailor agent behavior from day one.
* Monitor client usage via Agentiek dashboard to track token usage, incidents, and tasks.
* Clients can use free tools like Obsidian and Dropbox for knowledge management.
